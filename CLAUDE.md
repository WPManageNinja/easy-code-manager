# FluentSnippets (easy-code-manager)

## Translations

Use translations consistently: `__('text', 'easy-code-manager')` in PHP and `$t('text')` in Vue. Do not split translatable sentences across multiple `$t()` calls or concatenate a `$t()` result with a value; use placeholders (`$t('Delete %s', snippet.name)`, `$_n('%s snippet', '%s snippets', n)`) and `$_x('Active', 'Snippet status')` when one English word needs different translations in different places. Vue strings reach translators through the generated `app/Services/Trans.php`: after adding or changing `$t()` / `$_n()` / `$_x()` strings run `pnpm run translate` (the build fails on a stale map). Put a `<!-- translators: ... -->`, `/* translators: ... */` or `// translators: ...` comment directly before any string with placeholders; the lint fails on a placeholder string without one, on em/en dashes in UI text, and on keys with leading or trailing whitespace. Long paragraphs go in `reserved18n.json` under a short `Snake_Case_Key` and the template calls `$t('Snake_Case_Key')`. Regenerate the POT with `./build.sh --pot` (WP-CLI `wp i18n make-pot`, not Loco, which drops translators comments). See `docs/js-translations.md`.
